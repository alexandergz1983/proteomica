# proteomica

Este tutorial se basa en **Proteome Discoverer** un software comercial desarrollado por Thermo Fisher Scientific para el análisis de datos de proteómica basados en espectrometría de masas. Es una plataforma integral que permite procesar, analizar y visualizar datos proteómicos de manera eficiente.

Características principales:

1. Flujo de trabajo integrado
Procesamiento completo de datos LC-MS/MS

Identificación de proteínas y péptidos

Cuantificación (label-free, TMT, SILAC, etc.)

Anotación funcional

2. Módulos clave
Procesamiento de datos brutos
Lectura de formatos RAW (Thermo)

Extracción de espectros MS/MS

Desconvolución de datos

Búsqueda en bases de datos
Compatible con motores como:

SEQUEST HT

Mascot

MS Amanda

Byonic

Búsqueda contra bases de datos (UniProt, NCBI, personalizadas)

Cuantificación
Label-free: área bajo la curva, intensidad

Isobaric tags: TMT, iTRAQ

Metabolic labeling: SILAC, ¹⁵N

DIA/SWATH: procesamiento de datos DIA

Control de calidad
Filtrado por FDR (False Discovery Rate)

Validación estadística

Métricas de calidad de datos

3. Análisis estadístico y visualización
Análisis de abundancia diferencial

Anotación GO (Gene Ontology)

Análisis de rutas metabólicas

Visualización interactiva

Generación de reportes
